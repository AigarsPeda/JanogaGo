The page uses attachment-backed Gutenberg Image blocks with files in WordPress uploads. Replace them using the block's Replace control or upload files through Media Library. Remove an Image block to remove it from the page. Delete an attachment through Media Library to remove its uploaded files, after removing references from any page that uses it. The hero and lunch card share an attachment; the Latvian and English pages also share these attachments.

New content photos are stored only in WordPress uploads and Media Library, not bundled with theme code. The duplicate theme copies of the Lilas Yohane and Fidel Fernando photos were removed. Initial content setup resolves existing Media Library records by filename; import required images through WordPress before running it. Completed content migrations do not restore images or sections after an editor removes them.
